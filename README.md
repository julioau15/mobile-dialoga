# DiaLoga - Mobile

Este repositório contém o aplicativo mobile do DiaLoga, uma aplicação desenvolvida como parte do Trabalho de Conclusão de Curso (TCC).

O DiaLoga é uma plataforma que busca facilitar a interação e o acompanhamento entre pacientes e profissionais por meio da tecnologia.

---

## Repositórios do Projeto

O projeto está dividido em três aplicações:

* **Repositório principal:** https://github.com/julioau15/dialoga
* **Backend:** [github.com/julioau15/backend-dialoga](https://github.com/julioau15/backend-dialoga)
* **Frontend:** [github.com/julioau15/frontend-dialoga](https://github.com/julioau15/frontend-dialoga)
* **Mobile:** [github.com/julioau15/mobile-dialoga](https://github.com/julioau15/mobile-dialoga)

---

## Sobre o Mobile

O aplicativo mobile é responsável por disponibilizar as funcionalidades do DiaLoga em dispositivos móveis.

A aplicação permite que os usuários acessem e interajam com os recursos da plataforma por meio de uma interface adaptada para dispositivos móveis.

O aplicativo realiza a comunicação com o backend para o envio e recebimento das informações utilizadas pelo sistema.

---

## Objetivo

Desenvolver uma aplicação mobile que permita aos usuários utilizar as funcionalidades do DiaLoga de forma simples, organizada e adequada para dispositivos móveis.

---

## Comunicação com o Backend

O aplicativo mobile realiza a comunicação com a API desenvolvida no backend do DiaLoga.

[Backend do DiaLoga](https://github.com/julioau15/backend-dialoga)
